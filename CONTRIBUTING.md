# Contributing

Contributions must follow the guidelines below.

## Submitting a Patch

1.  [Open an issue](https://github.com/ng-log/ng-log/issues/new/choose)
    describing the bug or feature before starting work. State that you intend to
    address it so the work can be coordinated.
2.  [Fork](https://help.github.com/articles/fork-a-repo) the project and create
    a separate branch for each bug or feature. Keep each pull request limited to
    changes related to that work.
3.  Write commit messages using the [Conventional
    Commits](https://www.conventionalcommits.org/en/v1.0.0/) style. Begin each
    message with a type, an optional scope, a colon, and a concise description,
    such as `fix(logging): avoid duplicate output` or `docs: update contribution
    guidance`.
4.  Format all code changes according to the project's style before committing
    them. For C++ changes, run `clang-format` using the repository's
    `.clang-format` configuration. Do not reformat unrelated code.
5.  Push the commits to your fork and submit a [pull
    request](https://help.github.com/articles/creating-a-pull-request).
